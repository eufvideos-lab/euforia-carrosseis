# Grupo Euforia | Carrosséis do Instagram (@euforiagrupo)

Depósito das artes dos carrosséis e do gerador usado para criá-los.

- `carrosseis/AAAA-MM-DD_slug/`: slides (1080x1350), roteiro (`.json`) e legenda de cada post
- `gerador/`: script `render2.py` e a logo usados para gerar os slides

As imagens daqui são puxadas pelo Notion (Calendário de Conteúdo) e, na fase 2, pela automação de postagem.
